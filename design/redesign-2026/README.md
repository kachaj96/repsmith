# Repsmith redesign: trzy kierunki (prototyp)

Interaktywny prototyp do wyboru kierunku. Nie jest częścią aplikacji (service worker go nie ładuje).

Uruchomienie: otwórz `index.html` w przeglądarce (działa offline poza czcionkami z Google Fonts, bez nich używa czcionek systemowych).

- Kierunek A, B albo C, sześć ekranów, przełącznik Simple/Advanced.
- Pola, klawiatury, zapis serii, przełączniki i menu są klikalne.
- Pod telefonem: audyt Repsmith a Boostcamp, porównanie kierunków i rekomendacja.
